> Мини-игра на NASM с загрузчиком от KolibriOS, позволяющая запускать игру без полноценной операционной системы!

## 📖 Описание

Данный проект представляет собой легковесную мини-игру, написанную на ассемблере (NASM). Благодаря использованию загрузчика KolibriOS, игра способна загружаться и работать полностью автономно, без необходимости установки какой-либо операционной системы.

## ✨ Особенности

- 🚀 **Автономность:** Работает без какой-либо установленной ОС.
- 💾 **Легковесность:** Минимальный размер образа и мгновенная загрузка.
- 💻 **Гибкость запуска:** Поддерживает как эмуляторы x86, так и загрузку с реального железа.

## 🛠️ Требования

Для сборки проекта вам понадобятся:
- **WSL** (Windows Subsystem for Linux) или любая другая среда Linux
- Установленные системные пакеты: `nasm` и `mtools`
- **Python 3** для запуска скрипта сборки

## ⚙️ Сборка и запуск

1. Убедитесь, что в вашей Linux-среде (или WSL) установлены необходимые зависимости:
   ```bash
   sudo apt update
   sudo apt install nasm mtools
   ```
2. Запустите скрипт сборки:
   ```bash
   python3 build.py
   ```
3. **Запуск в эмуляторе:** Используйте любой эмулятор x86 (например, QEMU, Bochs, VirtualBox или [v86](https://copy.sh/v86/)), указав полученный образ дискеты в качестве загрузочного носителя.
   ```bash
   # Пример запуска в QEMU (замените image.img на имя вашего файла образа)
   qemu-system-x86_64 -fda image.img
   ```
4. **Запуск на реальном железе:** Запишите полученный образ дискеты на USB-флешку (например, с помощью утилиты `dd` в Linux или Rufus в Windows) и загрузитесь с неё через BIOS.
