# Мини-игра вместо ос
Данный проект является мини-игрой на nasm, с загрузчиком от KolibriOS, что позволяет загружать игру без ос. 

<img width="906" height="557" alt="{7435F98E-CFA1-489C-9A8C-09A2B3ECD7F1}" src="https://github.com/user-attachments/assets/e8fb0a20-9840-4796-ab3d-cc281a330468" />

Чтобы запустить игру необходим эмулятор [x86](https://copy.sh/v86/), но также можно записать образ дискеты на флешку и загрузиться с неё. <br>
Чтобы скомпилировать нужно запустить python скрипт build.py и иметь WSL с пакетами nasm и mtools.

Управление в игре осуществляется клавишами W, A, S, D (ходьба).
